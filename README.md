# 🐾 Bajen ZOO

En enkel webbplats för det fiktiva **Bajen ZOO**, skapad som ett webbprojekt med HTML och CSS.

## 📌 Om projektet

Webbplatsen innehåller information om Bajen ZOO och dess utbud. Besökaren kan bland annat:

* Se vad som finns att göra på zooet
* Se några av zooets djur
* Läsa information om djuren
* Anmäla sig till ett nyhetsbrev
* Hitta zooet via en inbäddad Google Maps-karta

## 🛠️ Teknik

Projektet är byggt med:

* **HTML**
* **CSS**
* **JavaScript**
* **Font Awesome**
* **Google Fonts**
* **Google Maps**
